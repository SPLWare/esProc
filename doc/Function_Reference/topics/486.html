iff x else …

Description:

iff statement.

Syntax:

iff 

x

else 

… 

Note:

A code-block structure for conditional branching. Executes the iff block or the else block depending on the result of x and places the value of the last calculation cell in the branch actually executed into the cell containing iff – not the cell containing else.

 

Parameter:

x

A Boolean expression.
