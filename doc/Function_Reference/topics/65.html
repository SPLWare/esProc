=. …

Description:

Take the preceding cell as the target object.

Syntax:

=. …

Note:

For calculation and executable cells that begin directly with ., preceding cell C is by default added as the target object. The expression is interpreted as =C.…. When searching backward for the preceding cell in the preceding row, if the cell immediately before it is empty, skip the entire preceding row.

Parameter:

…

An expression calculated on preceding cell C.

Example:
