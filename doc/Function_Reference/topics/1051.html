zip_add()

Description:
Append files to a ZIP archive, with support for setting a separate encryption password for each file.

Syntax:
zip_add(zip,files{,password})

Note:

The ZipCli external library function (See External Library Guide) appends one or more files to a zip file.

 

The function appends files to an opened zip archive, with support for batch append of wild characters * and ?.

(1) Values of both parameter files and parameter password can be passed in as the sequence. When both are sequences, match their values one by one in sequence to set passwords for different files.

(2) If a single string value is passed in as the password value, all appended files this time share the same password.

(3) When parameter password is omitted or an empty string is passed in, all newly-appended files are stored in plaintext.

Parameter:

zip

A zip file object.

files  

 The paths of to-be-appended files or FileObject file objects, with support for batch append by passing in a sequence of files.

password

Optional. It is he encryption password for the newly added files. Support a string or a sequence of passwords. When a sequence is passed, it corresponds one-to-one with the files sequence in order. When a password is specified, the corresponding file is encrypted; when omitted or an empty string is passed, the file is stored in plaintext.

Return value:
Boolean

Example:

 

A

 

1

=zip_open("D:/z2.zip")

Open a zip file.

2

=zip_add(A1,"D:/dir1/conn.java")

Add a single file in plaintext.

3

=zip_add(A1,["D:/a.xls","D:/b.txt"],["pwd1","pwd2"])

Sequence pairing: files and passwords correspond one-to-one in order.

4

=zip_add(A1,["D:/*.pdf","D:/*.csv"],["pwd1","pwd2"])

Wildcard sequence pairing: bound by position; when no file matches, the password position does not shift.

5

>zip_close(A1)

Close a zip file.
