forr cs;x

Description:

Collect the results to the master cell after iterating over and processing an ordered cursor by group.

Syntax:

forr cs;x

Note:

Iterate over the ordered cursor cs, grouped by field x. In each iteration, the value of the last calculation cell is automatically collected to form a cursor, which is assigned to the cell containing forr. In subsequent calculations, the forr master cell itself will be used directly as a cursor.

Parameter:

cs

An ordered cursor.

x

The grouping field.

Return value:

Cursor
